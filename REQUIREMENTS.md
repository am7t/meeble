# Requirements and scope

## Product direction

Meeble is a playful, customizable social space for a young audience, with profiles, social media, messaging, communities, and clothing resale. The first deliverable is a locally run, showcase-ready prototype; it is not a hosted public service.

## First slice

- Present a populated, believable sample feed on first launch.
- Provide a responsive, accessible social home screen with stories, navigation, sample community details, and create-post interaction.
- Save likes, comments, newly written posts, and hidden posts in local browser storage across launches.
- Run locally without paid services or public hosting; use a local relational database as features move to the server.
- Clearly communicate destinations and capabilities that are not implemented yet.

## Later work

Profiles and validated customization, in-app Polaroid capture, SQLite-backed feed persistence, account flows, media, stories, messaging, Grail, notifications, and feature-specific security tests remain future milestones. Real Google/Apple sign-in and email delivery require network configuration and are not part of a fully offline run.
