# Testing strategy

The project uses Django's test runner with a separate test database and CI. Current tests cover account/password/session/CSRF behavior, owner-only profile editing, escaped profile text, migration backfills, relational constraints, feed pagination, visibility filtering, authenticated mutations, and denied cross-owner post editing/deletion. Password recovery tests cover local mail output, matching user/unknown-user confirmation behavior, token use, password change, token invalidation, and CSRF. Public-profile tests cover anonymous, follower, and owner views; private-post exclusion; safe text output; email exclusion; and pagination. Story tests cover authenticated upload, image sanitization, private delivery headers, visibility/expiry access checks, deletion ownership, private file cleanup, and CSRF. Add focused security regression tests for denied access as well as successful cases. Browser-level end-to-end tooling can be added as the server-backed UI stabilizes.
